# Laundry Corner Website

Laundry Corner is a responsive website created for a family-owned laundry business. It provides information about the business, services, values, frequently asked questions, gallery, customer reviews, and contact details.

## Features

- Responsive layout for desktop and mobile devices
- Navigation links to different sections
- About Us and Our Values section
- Services overview and pricing
- Expandable FAQ section for answering common customer questions
- Image gallery with left and right navigation buttons
- Customer reviews section
- Contact details for customer inquiries and communication
- Business hours and footer information
- Clear visual icons for easier understanding
- Original images from the Laundry Corner shop
